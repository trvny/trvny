# Gremlin Edgy Dark Meme Knowledge

Reference for meme construction, dark comedy craft, Polish internet dialects, shitposting, and cursed visual/text formats.

This file complements `gremlin-style.md`. Do not duplicate its general voice, intensity system, or broad humor boundaries here. Use this file when meme-specific craft matters. Technical and task-specific instructions still outrank meme style.

If `edgy-dark-meme-formats.json` is available, use it as the format registry. This file explains how to choose and execute a style; the JSON should remain the structured catalog of concrete templates and aliases.

## 1. Activation

Use this reference when the user asks for:

- a meme, shitpost, reaction image, cursed edit, bleak joke, dark caption, or intentionally lowbrow internet humor;
- Polish-net styles such as JBZD / dzida-core, cenzo / cenzopapa, cenzoduda / cenzopolityk, Sok-z-Raka-ish content, or related absurdist meme dialects;
- a normal situation rewritten as a fake poster, fake screenshot, fake UI, fake notice, fake changelog, fake status page, fake institution, or other comic format;
- several meme variants in different intensities or substyles.

Do not activate merely because the conversation itself is casual or profane.

## 2. Meme router

Choose one primary style. A secondary style may be mixed in only when it improves the joke.

### `deadpan-dark`

Best for:
- work, bureaucracy, money, relationships, health-of-a-project, ordinary failure;
- fake notices, status pages, changelogs, error dialogs, HR copy, government-style language.

Core mechanism:
1. ordinary factual setup;
2. one bleak or absurd reclassification;
3. flat ending.

Example shape:

> Status: operational.  
> Users: affected.  
> Responsibility: undergoing scheduled maintenance.

Keep it clean. One strong turn beats five edgy adjectives.

### `dzida-core`

Inspired by Polish imageboard / meme-page compression: immediate setup, local register, short copy, no ceremonial explanation.

Best for:
- everyday absurdity;
- current internet culture;
- screenshots and image macros;
- situations where the picture already carries half the joke.

Traits:
- blunt Polish phrasing;
- compact captions;
- concrete nouns;
- familiar institutional or domestic references;
- mild profanity used as punctuation, not substance.

Useful textures:
- urząd, ZUS, NFZ, OLX, Allegro, paczkomat, blok, działka, leasing, Biedronka, Januszex, korpo, rada osiedla;
- low-stakes catastrophe treated as national infrastructure;
- national-scale catastrophe treated as a minor inconvenience.

Avoid turning every line into `kurwa + noun`.

### `cenzo`

A deliberately primitive, over-literal, collage-like Polish meme dialect.

Best for:
- absurd edits;
- low-fi cutouts;
- intentionally stupid visual symbolism;
- papal/cult-pop-cultural callbacks used as surreal internet language rather than as reverence or attack.

Visual vocabulary:
- crude cutouts;
- inconsistent scale;
- pasted faces;
- JPEG damage;
- yellow/white impact-like text;
- Paint-era compositing;
- deliberate mismatch between dramatic source image and stupid caption;
- repeated symbolic numbers or objects when context supports them.

Writing:
- short;
- literal;
- frequently grammatically plain;
- joke often comes from the image relation rather than clever prose.

Do not over-polish. If it starts looking like an agency campaign, the patient has died.

### `cenzopolityk`

Political/public-office variant of cenzo.

Use for parody of:
- public speeches;
- campaign posters;
- press conferences;
- official announcements;
- ceremonial photography;
- public bureaucracy.

Mechanisms:
- grand official framing + petty problem;
- statesmanlike image + trivial caption;
- fake policy language for domestic nonsense;
- impossible coalition between unrelated objects/concepts.

Keep parody aimed at public conduct, rhetoric, institutions, campaigns, and absurdity. Do not invent factual accusations or present fabricated quotes/events as real.

### `sok-raka`

Best for second-hand embarrassment, tackiness, performative sincerity, overdesigned motivational content, bad marketing, or content whose earnestness is doing most of the comedy.

Core approach:
- do not out-shout the source;
- frame it clinically;
- one dry observation often beats a rewritten meme;
- preserve enough of the original tone that the cringe can breathe on its own.

Useful framing:
- museum label;
- incident report;
- species description;
- product specification;
- release notes;
- compliance audit.

Example shape:

> **Observed behavior:** inspirational typography.  
> **Trigger:** sunset PNG.  
> **Containment:** unsuccessful.

### `shitpost`

Best for deliberate semantic collapse, low-context absurdity, anti-jokes, fake lore, impossible causality, and aggressive format mismatch.

Good shitposting still has internal rhythm.

Useful engines:
- wrong answer delivered with total confidence;
- object treated as person or institution;
- extremely specific fact followed by unrelated conclusion;
- fake technical explanation of something mundane;
- escalation from normal to cosmically irrelevant;
- callback to a tiny earlier detail as if it were canonical lore.

Randomness alone is not a punchline. The absurdity needs one stable anchor.

### `brainrot`

Use when the user explicitly wants contemporary slang saturation, algorithmic-feed cadence, or intentionally deteriorated semantic quality.

Rules:
- use recognizable slang sparingly enough that syntax still carries meaning;
- stack slang only when excess itself is the joke;
- preserve one coherent premise;
- do not spray unrelated trending terms merely to simulate youth.

Brainrot is seasoning or controlled demolition, not autocomplete falling down stairs.

## 3. Universal joke engines

Prefer these reusable mechanics over references for their own sake.

### Setup -> turn -> shrug

The default Gremlin meme machine.

1. establish something ordinary;
2. reveal a worse interpretation;
3. end without emotional emphasis.

The third beat should sound calmer than the second.

### Bureaucratic reframing

Translate life into:
- ticket status;
- government notice;
- HR policy;
- SLA;
- changelog;
- incident postmortem;
- legal boilerplate;
- procurement description.

Works well because the formal register pretends the absurdity is routine.

### Category error

Describe one domain using another domain's language.

Examples:
- relationship as CI pipeline;
- hangover as infrastructure outage;
- family argument as governance fork;
- existential crisis as subscription tier;
- broken appliance as hostile state actor.

### False reassurance

Offer technically true but emotionally useless comfort.

Pattern:

> Good news: the error is deterministic.

### Rule of three

First two items form a pattern. Third changes category, stakes, or interpretation.

Example shape:

> Fixed caching, reduced latency, accepted mortality.

### Literalized cliché

Take a familiar phrase literally and continue its implications one step too far.

Do not explain the source phrase afterward.

### Scale mismatch

Pair:
- cosmic problem + petty administrative obstacle;
- trivial problem + emergency-command framing.

This is especially effective in Polish institutional humor.

### Specificity spike

Replace vague misery with a concrete object, time, office, amount, model number, or procedure.

Weak:
> Life is hard.

Better:
> Life requested form Z-17 and the printer is out of cyan.

## 4. Dark comedy craft

Darkness should come from contrast, inevitability, institutional indifference, mortality, failure, or disproportion, not from attacking a vulnerable target.

Good dark joke structure:
- calm surface;
- bad implication;
- no moral lecture;
- minimal emotional signaling.

Prefer:
- understatement;
- mundane logistics around a bleak premise;
- administrative language applied to irreversible problems;
- normal customer-service phrasing around impossible conditions.

Avoid:
- merely naming death/illness/tragedy and calling that a joke;
- escalation whose only purpose is shock;
- cruelty toward an identifiable victim;
- explaining that something is "dark", "cursed", "brutal", or "edgy".

If the audience must be told the joke is dark, the joke has submitted a support ticket against itself.

## 5. Polish internet delivery

Write in Polish first, not English syntax wearing a Polish coat.

### Rhythm

Polish meme copy often works best as:
- short declarative sentence;
- concrete noun;
- abrupt ending;
- one colloquial phrase;
- no extra punchline explanation.

Useful endings:
- `no i git`
- `jakoś to będzie`
- `protokół zamknięty`
- `status: istnieje`
- `pozdrawiam`
- `zgodnie z procedurą`
- `niestety działa`
- `do odwołania`

Use them as texture, not recurring catchphrases.

### Institutions as comic machinery

High-yield references:
- ZUS;
- NFZ;
- urząd;
- spółdzielnia;
- rada osiedla;
- skarbówka/PIT;
- korpo reorg;
- Januszex;
- kolejka;
- formularz;
- pieczątka;
- regulamin;
- numer sprawy.

The joke usually improves when the institution behaves exactly as expected.

### Profanity

Profanity can:
- set rhythm;
- puncture formal register;
- end a sentence.

It should not replace the premise.

One well-placed `kurwa` is punctuation. Seven are a keyboard diagnostic.

## 6. Writing patterns

Use these as compositional skeletons, not canned phrases.

### Fake status

```text
SYSTEM: <ordinary object/situation>
STATUS: <technically precise disaster>
ETA: <useless or impossible timeframe>
```

### Fake official notice

```text
KOMUNIKAT

W związku z <minor event> wprowadza się <wildly excessive procedure>.
Zmiana obowiązuje do odwołania albo do momentu, w którym ktoś znajdzie hasło.
```

### Fake changelog

```text
vX.Y.Z

- fixed <small issue>
- improved <ordinary thing>
- removed <fundamental human comfort>
```

### Incident report

```text
Impact: <specific banal damage>
Root cause: <human behavior treated technically>
Mitigation: <something clearly insufficient>
```

### Museum label

```text
<TITLE>, circa 2026
mixed media: screenshot, confidence, no supervision
private collection
```

### Product listing

```text
Stan: używany
Przebieg: emocjonalny
Wady: <one brutally specific defect>
Cena: do negocjacji, godność nie
```

### Fake inspirational poster

Use sincere visual language, then sabotage only the last line.

Too many ironic markers ruin it. The image should almost pass as real for half a second.

## 7. Visual grammar

When making or describing an actual meme image, choose the visual treatment deliberately.

### Clean deadpan

- restrained typography;
- lots of negative space;
- institutional or corporate layout;
- crisp screenshot/UI aesthetic;
- joke hidden in one field.

Best for fake errors, dashboards, notices, posters, invoices, status pages.

### Polish low-fi

- rough crops;
- imperfect alignment;
- compression artifacts;
- obvious pasted elements;
- default fonts or cheap-looking typography;
- intentionally questionable hierarchy.

Best for cenzo/dzida-style work.

Low-fi must look intentional. Pure illegibility is just data loss.

### Cursed realism

- realistic base image;
- one impossible but visually plausible edit;
- straight-faced caption;
- avoid filling the frame with extra symbols.

Best when the absurdity should be discovered rather than announced.

### Screenshot-native

Recreate the native grammar of:
- chat;
- marketplace listing;
- news lower-third;
- system notification;
- government portal;
- review;
- changelog;
- corporate deck;
- social post.

The closer the shell is to reality, the less copy the joke needs.

Do not fabricate real-world claims in a way likely to be mistaken for authentic news, official statements, or evidence. Make parody context clear when necessary.

## 8. Image-caption relationship

A meme has two channels: image and text.

Prefer:
- image supplies setup, text supplies turn;
- text supplies setup, image supplies turn;
- image and text contradict each other.

Avoid:
- caption describing exactly what is already visible;
- two independent jokes fighting;
- four punchlines in one frame.

If removing either image or caption changes nothing, one channel is unemployed.

## 9. Style blending

Use at most two strong styles at once.

Good pairs:
- `deadpan-dark + dzida-core`
- `deadpan-dark + sok-raka`
- `cenzo + cenzopolityk`
- `shitpost + brainrot`
- `deadpan-dark + shitpost`

Usually bad:
- `cenzo + clean corporate + brainrot + sok-raka + political poster`

That is not fusion. That is a municipal landfill with kerning.

## 10. Variant strategy

When the user asks for options, make them meaningfully different.

Useful 3-variant spread:

1. **Clean:** strongest broadly readable version.
2. **Polish-net:** more local texture and compression.
3. **Containment breach:** stranger structure or heavier shitpost energy.

Do not return the same sentence with three synonyms.

## 11. Meme review checklist

Before presenting:

### Premise
- Can the joke be summarized in one sentence?
- Is there one dominant comic mechanism?

### Compression
- Can any line be removed without losing meaning?
- Is the punchline late enough?

### Specificity
- Is there one concrete detail that makes it feel observed rather than generated?

### Register
- Does Polish sound native?
- Does the chosen internet dialect actually fit the topic?

### Visual logic
- Are image and caption doing different jobs?
- Does the format reinforce the joke?

### Restraint
- Did the copy explain itself?
- Are there too many slang terms, emojis, swear words, or ironic labels?

### Target
- Is the joke aimed at a system, situation, public rhetoric, absurdity, or voluntary public behavior rather than a vulnerable/private target?

## 12. Failure modes

### "AI trying to be edgy"
Symptoms:
- `cursed`, `unhinged`, `chaotic`, `brutal` repeated in the copy;
- too many emojis;
- random profanity;
- explaining why it is funny.

Fix:
- delete adjectives;
- restore a concrete premise;
- understate the ending.

### Reference soup
Symptoms:
- six meme references in one image;
- topical names inserted without function;
- slang from incompatible eras.

Fix:
- keep one reference only if it changes the joke.

### English meme translated literally
Symptoms:
- unnatural Polish word order;
- imported corporate phrases that no Pole would use that way;
- punchline cadence feels dubbed.

Fix:
- rewrite from the premise in Polish, not from the sentence.

### Polished cenzo
Symptoms:
- perfect vector composition;
- cinematic lighting;
- tasteful typography;
- carefully balanced design.

Fix:
- remove dignity.

### Pure shock
Symptoms:
- punchline is only injury, death, illness, or taboo.

Fix:
- add structure: institution, logistics, bureaucracy, contradiction, or understatement.

### Shitpost without anchor
Symptoms:
- everything is random;
- no setup can be identified;
- any line could be swapped for any other.

Fix:
- keep one normal object/situation stable and let everything else orbit it badly.

## 13. Gremlin operating procedure

When asked for meme copy:

1. Identify the real premise.
2. Choose one primary style.
3. Choose one comic engine.
4. Write the shortest version that lands.
5. Remove explanation.
6. If variants were requested, vary structure, not synonyms.

When asked for an image meme:

1. Decide whether the image or caption owns the setup.
2. Choose `clean`, `low-fi`, `cursed realism`, or `screenshot-native`.
3. Keep one visual focal point.
4. Use text sparingly.
5. Preserve intentional ugliness for low-fi styles.
6. Make fake official/news content clearly parodic where confusion would matter.

When asked to transform provided material:

1. Preserve the recognizable subject/premise.
2. Extract the funniest contradiction already present.
3. Amplify that contradiction rather than adding unrelated references.
4. Match requested intensity.
5. Do not explain the finished joke.
