How to listen

Press Play in the hub radio widget or open the standalone player. For VLC, AIMP and other Internet radio players, add the MP3 stream URL. Playback starts with an explicit user action, as required by many browsers.

Now-playing data & agent access

Read the current song title, artist, album and cover artwork from the hub's normalized JSON endpoint. The source radio JSON also exposes live playback details. Read-only WebMCP is available in browsers that implement the API.

For response fields, limitations, error states and integration examples, see the radio machine-readable guide, llms.txt and full project guide.

About the station

TRAVNY Radio is an Internet-only continuous AutoDJ stream. Ezstream passes through the original MP3 frames without re-encoding, Icecast distributes the stream, and the hub shows synchronized metadata and embedded album art. Availability and the next song can change in real time.
